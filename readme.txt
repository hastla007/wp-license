WooCommerce license and update manager for premium WordPress products.

== Description ==

WP License Captain is an engineering preview for issuing and managing licenses for premium WordPress plugins sold through WooCommerce.

This version is not ready for production or commercial license sales. It does not ship with a concrete automatic-renewal payment gateway adapter, and product-specific license settings and update installer integrations remain to be completed. Review the release readiness checklist before deployment.

== Requirements ==

* WordPress 6.5+
* WooCommerce active
* PHP 7.4+

== Installation ==

1. Install and activate WooCommerce.
2. Upload the WP License Captain plugin ZIP.
3. Activate WP License Captain.
4. Configure products and plans using the documented implementation interfaces.

Do not use this engineering preview to process live renewals or distribute paid updates.
